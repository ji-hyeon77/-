## 구현 범위와 보존

- 기록은 현재 브라우저 로컬 저장이다. 로그인 클라우드 동기화 보호자 계정은 미구현이다.
- 도우미는 고정 FAQ 매칭이다. AI Agent LLM RAG 상담이 연결되지 않았으며 개인 처방을 결정하지 않는다.
- 최종 URL과 기존 QR을 유지한다. 기존 PNG의 해독값은 최종 URL과 일치했다.
- 공개 폴더는 소개와 검증 문서이며 최종 배포 실행 소스 전체의 공개 저장소가 아니다. `demo`는 별도 코드이고 이번 검증의 대상이 아니다.
- 비공개 저장소는 초기 기획과 향후 AI 구상을 보관하는 별개 역할이다. 실제 배포 기능은 최신 검증 문서를 기준으로 구분한다.
- main 배포코드 demo QR은 이 작업으로 변경하지 않는다. 검토 브랜치와 초안 PR만 갱신한다.

과거 고유47개 자동 시험 통과는 2026년11월17일 문서 기록이며 이번에 그 시험을 재실행한 결과가 아니다. 현재 실제 환자 보호자 참여자는0명 사용자 KPI와 임상 효과는 미측정이다. 실기기 모바일 인쇄 알림 수신 접근성 검증도 남아 있다. 가상값만 체험에 사용한다.
