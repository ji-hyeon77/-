## 어떤 제품인가요?

혈액투석 환자의 **체중(가정/투석 전/투석 후)·혈압·혈당·증상·메모**를 필요한 만큼 기록하고 **정기·예외 투석 일정**과 함께 확인하여, **진료용 사실 요약**을 만들도록 돕는 모바일 웹앱 MVP입니다.

## PM 관점에서 무엇을 했나요?

| 항목 | 내용 |
|---|---|
| 문제 정의 | 임상 경험으로 파악한 '측정 맥락 보존'과 '진료 준비의 단절'을 **검증할 가설**로 정의 |
| 목표 사용자 | 스마트폰으로 직접/가족 도움을 받아 기록하는 성인 혈액투석 환자(가설) |
| MVP 우선순위 | 매일 모든 값 입력을 강요하지 않고 **단일 항목 기록 → 확인 → 요약** 흐름에 집중 |
| 안전·신뢰 | 로컬 저장·백업/복원, '미기록≠증상 없음', 의료적 판단·처방 추천 금지 |
| 검증 | 이전 문서의 고유 자동 시험 **47개 통과 기록**; 2026-11-19 현재 재실행 여부는 별도 |
| 보류 범위 | AI 상담, LLM/RAG, 개인 맞춤 처방, 로그인·클라우드 동기화, 보호자 전용 계정 |

## 제품 의사결정 사례

**왜 AI 상담 대신 기록 안정성부터 다뤘나?**  
혈액투석의 체중은 투석 전/후와 가정 측정의 의미가 다르며, 측정시간이나 맥락이 누락되면 사용자·의료진의 이해에 혼란이 생길 수 있습니다. 따라서 초기 MVP에는 **다회 기록을 덮어쓰지 않고 저장**하고 **진료용 요약에 원래 측정 사실만 표시**하는 일에 우선순위를 두었습니다.

이는 실제 환자 사용자 조사의 결론이 아닌 **임상 관찰에 기반한 PM 가설과 우선순위 판단**입니다.

## 검증 결과를 정확히 읽는 법

- **이전 검증 문서:** 2026-11-17 포트폴리오에 자동 시험 **30개(공통 데이터·저장) + 17개(HTML·이벤트) = 고유 47개** 통과 기록. Asia/Seoul 및 UTC 환경별 반복 시행은 **94개 고유 테스트가 아님**.
- **현재 사용자 KPI:** **미측정**. 독립 완료율 80% 및 기록 60초 이내 등은 향후 테스트를 위한 **목표 가설**.
- **미검증:** 실제 환자 사용성 평가, 임상 효과, 실기기 알림·인쇄 신뢰성, 의료진 전체 콘텐츠 검토.

## 기술·배포 범위

- **서비스 링크는 기존 HARU 최종 배포본**으로 연결합니다. 기존 QR과 배포 주소는 변경하지 않았습니다.
- 이 공개 GitHub 디렉터리는 **프로젝트 설명 및 PM 검증 문서 중심**입니다. 기존 최종 배포 앱의 실행 원본 전체가 게시되었다는 뜻이 아닙니다.
- 별도 데모 파일과 최종 배포 앱은 동일 소스가 아니므로 제품 근거로 혼용하지 않습니다.
- 기록은 브라우저에 로컬 저장되며 클라우드 동기화·진단·처방 기능은 없습니다. **가상 데이터로만 체험**하고 실제 개인·건강정보를 입력하지 마세요.
- 고정 FAQ는 AI 상담이 아니며 응급 증상에는 119 도움 요청을 안내합니다.
