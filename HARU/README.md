## 프로젝트 소개

혈액투석 환자가 병원 밖에서 체중, 혈압, 혈당, 증상 및 메모를 기록하고, 투석 일정과 함께 확인하며 진료용 요약을 준비할 수 있도록 만든 모바일 웹앱 MVP입니다.

## 주요 기능

- 체중·혈압·혈당·증상·메모 기록과 조회
- 정기 투석 요일 및 날짜별 일정 관리
- 혈압·혈당 수첩과 진료용 요약
- 브라우저 내 기록 저장, 백업·복원
- 고정 FAQ와 응급상황 도움 요청 안내

## 사용 안내

- 시연용 MVP이며 실제 환자 대상 임상 검증이나 상용화는 완료되지 않았습니다.
- 이름·병원명·연락처 등 실제 개인정보 대신 가상 데이터를 사용해 주세요.
- 기록은 현재 브라우저에 로컬 저장되며 클라우드 동기화는 지원하지 않습니다.
- 진단이나 처방 변경을 제공하지 않습니다. 응급 증상은 119에 연락해 주세요.
