## 프로젝트 개요

혈액투석 환자의 병원 밖 체중, 혈압, 혈당, 증상, 메모 기록을 투석 일정과 연결하고 진료 시 요약해 확인하도록 설계한 의료 생활관리 개인 프로젝트입니다.

## GitHub 시연본에 구현한 것

- 기록 날짜 선택, **체중·혈압·혈당·증상·메모** 입력 및 수정·삭제
- 같은 날짜의 여러 측정값 기록, 측정 시점과 시간
- **정기 투석 요일·시간** 저장 및 날짜별 일정 변경
- 혈압·혈당 수첩, 기간별 진료용 텍스트 요약, 간단한 체중 그래프
- **브라우저 로컬 저장**, JSON 백업·복원(기존 날짜는 보존), 직전 변경 되돌리기
- 고정 FAQ와 위험 증상 시 119 안내

## 버전 및 정확성 안내

**GitHub 시연본은 기존 HARU 최종 화면과 기획 명세를 바탕으로 새로 구현한 독립 버전입니다.** 기존 배포본과 완전히 같은 소스코드가 아니며, 기존 앱과 모든 동작이 동일하다고 주장하지 않습니다. 코드는 이 공개 저장소에서 확인할 수 있습니다.

기존 HARU 배포 앱은 위의 별도 URL에서 계속 열 수 있습니다. GitHub Pages 정식 주소는 아직 활성화되지 않았고, 현재 GitHub 시연본 URL은 HTML 미리보기 서비스 주소입니다.

**의료 안전 및 개인정보**

- 시연용 MVP: 실제 환자 대상 임상 평가 및 상용화 없음
- 실명·연락처·병원명 등 개인정보 대신 가상 데이터만 입력
- 기록은 현재 브라우저에만 저장, 기기를 바꾸면 자동 동기화되지 않음
- FAQ는 고정된 일반 정보이며 AI 상담·LLM·RAG나 개인 처방을 제공하지 않음
- 흉통, 심한 호흡곤란, 의식 저하 등 위험 증상은 119 연락 안내
