# HARU 사용자 시나리오 검증표

페르소나는 임상 경험에서 도출한 가설이다. 아래 결과는 실제 환자나 보호자의 사용성 평가가 아닌 AI 보조 QA 수행자의 기능 검증이다. 환자 0명 보호자 0명이며 독립 수행 능력과 이해도는 미평가다.

|---|---|---|---|---|
| US-01 | 환자가 투석 전후 체중 기록 | 같은 날 62.4 전 08시 60.8 후 12시 별도 표시 | 덮어쓰기 시점 시간 혼동 | PASS 기능 UI-05 UI-08 가정 체중 UI는 미실행 |

| US-05 | 보호자가 같은 기기에서 진료 요약 확인 | 기간에 맞는 값 시점 메모 상태를 찾음 | 없는 값 추정 다른 기간 혼입 | PASS 기능 7일과 18일 단일 기간 UI-08~09 참여자 성공률 아님 |

US-05의 보호자 역할은 같은 기기를 사용하는 도움 맥락이다. 보호자 계정 실시간 원격 공유 클라우드 동기화는 구현하지 않았다. 위 8개를 실제 사용자 8명 평가로 읽지 않는다.

## 다음 사용성 평가 계획

환자 5명 보호자 2명의 가상 과업 평가를 제안한다. 모집과 동의 및 개인정보 취급을 정리한 뒤 실제 건강수치 대신 제공된 가상값을 사용한다. 최초 시도를 분모로 독립 완료 여부와 시작 종료 시각 도움 횟수 오류를 기록한다. 실패 후 재시도는 별도 행으로 남긴다. 안전 질문은 가상 문구의 안내 이해만 확인하며 실제 증상에 대한 의학 판단을 요구하지 않는다.

독립 완료율 80퍼센트 이상 기록 중앙값 60초 이하는 목표 가설이다. 아직 참여자가 없어 실측값은 없다.
