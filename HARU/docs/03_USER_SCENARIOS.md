# HARU | 사용자 시나리오 · 과업 · 인수 기준

> **페르소나는 가설이며 인터뷰로 확정된 실제 사용자 집단이 아님.**  
> 실제 참여자 없이 작성한 PM 검증 계획. 기존 배포 MVP와 별도 계정·클라우드·AI 기능을 혼동하지 않는다.

## Persona A — 직접 기록하는 혈액투석 환자
- 사용 맥락: 투석 일정이 있고 스마트폰으로 간단한 숫자 입력 가능.
- Job to be done: "집과 투석실에서 잰 체중을 헷갈리지 않게 남기고 다음 진료 때 보여주고 싶다."
- 검증할 위험: 날짜·시간·측정 시점이 빠지면 수치 해석이 달라질 수 있음.

### US-01 | 투석 전후 체중 구분 (P0)

**Given** 정기 투석일과 가상의 같은 날짜  
**When** 투석 전 62.4kg, 투석 후 60.8kg을 서로 다른 시간에 기록  
**Then** 두 값과 측정 시점·시간이 별도로 저장되고 요약에 나타남  
**실패 기준** 전후 값 덮어쓰기, 없는 시간을 임의 생성, 무조건 평균으로 합침  
**관찰** 독립 완료·소요 시간·정확한 시점 이해

### US-02 | 투석 일정 이동 (P0)

**Given** 월·수·금 정기 투석 요일  
**When** 안내받은 일정에 맞춰 특정 수요일을 비투석일, 다음 목요일을 투석일로 수정  
**Then** 예외가 한 날짜당 하나씩 보존되고 기본 요일 변경 후에도 남음  
**실패 기준** 자동으로 투석 횟수·일정을 임의 처방하거나 예외가 사라짐

## Persona B — 필요한 항목만 기록하는 환자
- Job to be done: "혈압만 두 번 재도 다른 건강 항목을 다 채우지 않고 기록하고 싶다."

### US-03 | 하루 두 번 혈압 저장 (P0)

**Given** 비투석일  
**When** 08:30에 120/80, 20:30에 128/82를 각각 저장하고 첫 기록만 수정  
**Then** 시간순 2건이 보존되며 첫 기록 수정이 두 번째 기록에 영향을 주지 않음  
**실패 기준** 둘 중 하나가 덮이거나 혈당 미입력 값을 0으로 표시

### US-04 | 증상 없음과 미기록 분리 (P0)

**Given** 어떤 증상 항목도 선택하지 않은 상태  
**When** 저장을 시도  
**Then** '증상 없음'을 자동 생성하지 않고, 사용자가 명시적으로 선택할 때만 저장  
**실패 기준** 미기록이 임상적으로 '무증상'으로 해석됨

## Persona C — 같은 기기에서 기록을 돕는 보호자
- 보호자 전용 계정이나 타 기기 실시간 공유는 구현하지 않았음.
- Job to be done: "진료 전 환자와 함께 빠진 기록을 보고 정리하고 싶다."

### US-05 | 진료용 요약 (P0)

**Given** 서로 다른 날짜의 체중·혈압·혈당·메모 기록  
**When** 최근 7일/14일/사용자 지정 기간을 선택  
**Then** 해당 기간의 기록·시점·메모와 '미기록' 표시가 확인 가능  
**실패 기준** 없는 날짜를 '정상'으로 추정하거나 진단·제거 수분량 권고를 생성

### US-06 | 백업·복원 (P0)

**Given** 기존 브라우저에 11/18 기록이 있고 백업 파일에 11/18·11/19 기록이 존재  
**When** 파일 복원  
**Then** 원래 11/18 기록은 유지되고 없는 11/19 기록만 추가되며 투석 일정은 바뀌지 않음  
**실패 기준** 기존 날짜 데이터 덮어쓰기·일정 변조

## Safety scenario — 의료적 오해 방지

### US-07 | 응급 도움 우선 (P0)

**Given** FAQ 도우미 화면  
**When** "가슴이 아프고 식은땀이 나요" 등의 위험 표현을 입력  
**Then** 일반 생활관리 팁보다 즉시 응급 도움 요청과 119 안내를 우선 제시  
**실패 기준** 응급 상황을 가벼운 증상으로 확정하거나 전화 안내가 누락  
**범위:** 제한된 입력 패턴 테스트. 모든 가능한 문장을 인식한다고 주장하지 않음.

### US-08 | 처방 변경 요청 거절 (P0)

**When** "인슐린을 몇 단위 맞아야 하나요?", "오늘 물 얼마까지 마셔도 되나요?" 질문  
**Then** 개인 투약량·수분 제한량을 결정하지 않고 담당 의료진 지침 확인을 안내  
**실패 기준** 개인 데이터 없이 처방 숫자 생성

## 검증 프로토콜 (아직 미실행)

- **제안 표본:** 환자 5명, 보호자 2명. 모집·동의·개인정보·사용자 안전을 적절히 검토한 후 실시.
- **과업:** 기본 기록, 다회 측정, 수정·복구, 일정 이동, 진료용 요약 찾기, 응급 안내 해석.
- **기록:** 시나리오별 독립 완료 여부, 과업 시작·종료 시간, 도움 요청 횟수, 오류, 인터뷰 메모.
- **평가 목표(미달성):** 독립 완료율 ≥80%, 단일 기록 과업 중앙값 ≤60초. 표본과 측정 편향을 함께 보고.
- **주의:** 실제 증상을 입력받거나 의료적 판단을 시키는 임상 평가가 아니라 **가상 데이터를 사용하는 사용성 과업**임.
